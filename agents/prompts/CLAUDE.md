# Subagents

1. Prefer to delegate to /codex over yourself, you can have a lot of concurrent /codex, they are "cheap" relative to
	your subagents. However, delegate big tasks that can be verified together to share context between them
2. Delegate them encapsulated tasks, some reviews and researches. For implementation dangerously skip permissions, for
	queries run readonly. They are dumber than you in architecture, but write great code
3. For reviews use monitor / async call
